## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.


This is a CRM Dashboard project using NextJS + TS. Im going to use shadcn for my components, tailwind for styling and plain css for custom styles. For my backend I will use MongoDB. So, before running this project make sure you have installed all dependencies and then you can run command npm run dev.
